在 TypeScript 中，為值指定型別有三種方式。Type Annotation (型別註釋)、Type Inference (型別推論)、Type Assertions (型別斷言)。

# Type Annotation (型別註釋)

開發者可以主動明確宣告型別，讓 TypeScript 在編譯階段進行更嚴格的型別檢查，避免因錯誤型別導致的 bug。

# Type Inference (型別推論)

在沒有明確指定型別時，TypeScript 會根據變數的初始值或表達式的結構自動推斷型別。

# Type Assertions (型別斷言)

TypeScript 中的型別斷言是一種機制，用來告訴編譯器「我知道這個值的型別」，即使它現在是 any 或 unknown 。

型別斷言不會改變執行時的資料型別，只是用來協助編譯器進行靜態檢查。
