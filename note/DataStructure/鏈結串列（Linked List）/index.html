# Linked List

# 定義

由一組 節點 (Node) 所組成的 有序串列 ，各 Node 除了 Data 欄 之外，另外有 >= 1 個 Link 欄 (或稱 Pointer)，用以指向其他 Node 之位址。

# 特性

  1. 各 Node 不一定要占用連續的記憶體空間。

  2. 各 Node 之型態 (Data Type) 不一定要相同。

  3. 僅支援循序存取。

  4. 新增 / 刪除 Node 容易。

# 種類

  1. 單向鏈結串列（Single Linked List）—— 1 個 Link 欄
  2. 環狀鏈結串列（Circular Linked List）—— 1 個 Link 欄
  3. 雙向鏈結串列（Double Linked List）—— 2 個 Link 欄

# 單向鏈結串列（Single Linked List）

# 定義

由一組 節點 (Node) 所組成的 有序串列 ，各 Node 除了 Data 欄 之外，另外有 1 個 Link 欄 (或稱 Pointer)，用以指向其他 Node 之位址。

# 基本操作

# 插入節點

插入節點可分三種情況，分別是在 List 的最前面、中間、最後面三種情況。

# 前面

建立一個新的 Node，之後將此 Node 的 Link 指向原本的 Head，更新 Head 為新 Node，使它成為新的起點。

# 中間

假設要將新的 Node 插在第 i 個位置，先將新節點的 next 指向原本第 (i+1) 個節點，再把第 i 個節點的 next 改成指向新節點。

# 後面

建立一個新的 Node，將最後一個節點指向新節點即可。

# 刪除節點

刪除節點跟插入節點一樣，分成前、中、後三種情況。

# 前面

直接把 head 移到 head.next ， 原本的第一個節點會被「丟掉」（若語言有垃圾回收就會自動釋放記憶體，否則需要手動釋放）。

# 中間

找到欲刪除節點的前一個節點，讓它的 next 指向欲刪除節點的下一個節點，欲刪除節點就被「跳過」了。

# 後面

找到倒數第二個節點把它的 next 設為 null 即可。
