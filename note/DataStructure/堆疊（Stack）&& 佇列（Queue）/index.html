堆疊（Stack）&& 佇列（Queue）

# Stack

# 定義

堆疊（Stack） 是一種 後進先出（LIFO, Last In First Out） 的資料結構。

# 特性

  1. 存取限制：只能在 頂端（Top） 進行插入與刪除操作。

  2. 操作單純：僅支援兩種主要操作：

  • Push：將元素放入堆疊頂端。

  • Pop：移除並回傳堆疊頂端元素。

  1. 後進先出：最後放入的元素會最先被移出。

# 實作方式

  1. 陣列實作

  2. 鏈結串列實作

# Queue

# 定義

佇列（Queue） 是一種 先進先出（FIFO, First In First Out） 的資料結構。

# 特性

  1. 存取限制：只能在 尾端（Rear）插入，在 前端（Front）刪除。

  2. 操作單純：僅支援兩種主要操作：

  • Enqueue：將元素放入尾端。

  • Dequeue：移除並回傳前端元素。

  1. 先進先出：最先進入的元素會最先被移出。

# 實作方式

  1. 陣列實作

  • 使用陣列模擬，但若僅用單純陣列，刪除前端元素會導致元素搬移 時間複雜度 O (n)。

  • 改進方式：環狀陣列（Circular Queue），使用兩個指標 front 和 rear 來追蹤位置。

  1. 鏈結串列實作

# Stack vs Queue 比較

特性Stack（堆疊）Queue（佇列）
存取規則後進先出（LIFO）先進先出（FIFO）
插入位置頂端（Top）尾端（Rear）
刪除位置頂端（Top）前端（Front）
實作方式陣列、鏈結串列陣列（環狀）、鏈結串列
