# 解題思路

利用 Stack 解，遍歷給定的字串 s ，當遇到左括號就存入 Stack 裡；遇到右括號時，需要將相同類型的左括號閉合。於是我們將 Stack 裡最上面的左括號取出並判斷是否是相同類型的，不是相同類型或是 Stack 裡沒東西就回傳 false。
遍歷結束後，Stack 裡沒東西就回傳 true

這邊用 哈希表 主要是為了 快速查找括號的對應關係。
